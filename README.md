### 硬件说明

参考官方开源的硬件，官方的硬件对于硬件新手来说是不够友好的，电阻电容的封装基本都是0402，对很少手焊的的朋友来说是不够友好的，后续有时间的话想依旧官方的硬件方案二次修改，把封装改为0603的，现在对我焊接时利用的小技巧进行相应的总结。本次焊接仅仅使用了焊笔和风枪，对条件有限的朋友还是有一定的参考价值。废话不多说了，开始介绍。

### 焊接时注意

对于主控板，建议先将顶部的接口焊接好，在焊底部的元件，因为高温下接口会吹坏，建议没有加热台的话，先在焊盘上涂上锡膏，将风枪温度调节到 300~330 的温度吹PCB的底部，另一只手在调节端正/接口的位置（认为摆得很好了，也可以不用管）直达锡膏融化即可。

![main_top](https://github.com/OoOZzZzzzz/VoCat-Replication/blob/main/doc/image/main_top.jpg?raw=true)

- ①和②都是LCD屏幕的接口，焊①就行了，②也不是特别好焊，连锡了就麻烦了，为了减少不必要的工作和麻烦②可以直接不焊
- ①可以先上一些锡膏均与涂抹，如何风枪在底部吹化锡膏或直接利用焊笔，但最后都要焊笔脱一遍调整，保证每一个焊盘均匀有锡且防止锡过多，提高一次焊接的成功率，最后焊接时，均匀涂上助焊剂，一是防止端正乱动脱离，二是使得端正引脚与焊盘上的锡均匀接触。

- ①处后接屏幕时牢记**白线朝上，金属触点朝下**，如图所示，不要接反了，③处也要记住焊接时不要方向反了，最后的FPC排线，金属触点朝外。
- ④处接电池，最后来做，一定要保证电源板测试通关，供电没问题，正确接上电池，不要接反了（见丝印）
- 最后⑤处我使用的是外接天线的主控，我更推荐用外接天线的，但是也还好，看个人喜好



对与主控板，最难焊接的地方莫过于背面的QFN封装的器件，这些器件基本与音频解码/播放相关，主控板上其实只包含：主控、音频和陀螺仪，两个外设，设计十分合理。

![main_bottom](https://github.com/OoOZzZzzzz/VoCat-Replication/blob/main/doc/image/main_bottom.jpg?raw=true)

- 先利用风枪完成③和①，然后在用焊笔焊接好排针⑧，插上电源板（**供电正常哈**），然后**先接好屏幕，下载程序后看屏幕正常与否，再继续焊接后面部分**。
- 这样的话后续焊接可能会有点困难，但我更为推荐，因为屏幕部分接口可以说时这块板子上最难的部分，所以这样要**备用上锡纸，后续焊接时用锡纸包裹好排针⑧的部分**，再焊接。
- 后续就简单了，仅需利用风枪和锡膏就行了，焊接好②运放后再测试一下，以上焊接的部分供电都是由电源板提供，测试通过后含下一部分。
- 焊接音频的单独供电⑦，然后供电测试，利用万用表测试，地直接接上主控外壳就行了，VCC在顶部的端子③就可以找到，电源3.3v左右就没什么问题了，可以直接完成其余所有部分了。
- 这里两个音频芯片的焊接还是利用之前焊接屏幕接口①的方法（但是这里风枪是在芯片的上方吹，比较下面都焊好了，会吹坏的，芯片相对于端子来说可以直接利用风枪），建议先焊接好芯片后再焊接外围电阻电容。焊接时用镊子调整，按一按，多出来的锡，最后用焊笔在外围脱焊休整就行了（这也是为什么要先焊芯片的原因），最后可以看见图中⑥，有一角连锡，其实没关系，这里两个角就是芯片的供电部分。



电源板时最为重要的部分，应该最先焊接测试好，这里电源板的顶部，经过观察，都可以使用，焊笔直接焊接，故最后焊接，也相对最简单，但这里有几点要注意：

![power_top](https://github.com/OoOZzZzzzz/VoCat-Replication/blob/main/doc/image/power_top.jpg?raw=true)

- 这里的①没焊接，后面测试时怎么办？后面利用学生电源测试供电正常与否时，直接用镊子或者金属丝短接一会儿就可以达到开关效果了。
- 指示灯这里要**注意**：中间②处有两个焊点，对应中间焊盘处只焊接到左侧，右侧和最右边的阳极焊接在一起如③这样焊也可以。阳极参考芯片手册可知是有色带的地方，测试时不亮是正常的，这仅仅与Type_c供电相关，至于为什么，**可以用万用表的通断档测试，红接③，用黑表笔试探其他触点你就知道了，实在不知道哪个地方是正负极，这个方法也可以测出哪一端是正负极（电源”红进黑出“嘛）**，这是应该很有用的办法



![power_bottom](https://github.com/OoOZzZzzzz/VoCat-Replication/blob/main/doc/image/power_bottom.png?raw=true)

- 最核心的地方，我们先焊接④Type_c接口，由于这里焊盘很大，我们在最外边均匀涂一点锡膏就行了，然后直接用焊笔脱焊，适当加点助焊剂，就可以达到④那样的效果，最后在从另一侧用焊笔焊好四处Type_c外壳的四个角就行了。**最后，一定要用万用表的通断档测试，以防电脑受伤**。
- 然后焊接剩下部分，下面顺序就没啥了，可以焊好⑤开关芯片后，焊接①DCDC电源部分，这里可以看到我是电阻串联的，比较抽象，但不可谓不是一个方法，这里是22.1k，就这一处用到了该阻值，实在是忘了买，于是利用 20k+1k*2+100R 组合而成，实际测试丝毫没问题，误差不大。然后就可以测试一下，供电是否正常了。
- 紧接着焊③和②，这部分最难的是②，要注意②**处有与主控间I2C通信，但不影响供电，所以下载完代码，当终端中报错I2C通信相关的内容，可以来看看这里，可能是这个芯片坏了或者说没焊接好（本人就被这个折磨了很久，一直以为是主控上的外设焊接有问题或者坏了），建议多多检查这里**
